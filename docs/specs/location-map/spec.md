# 후보지 위치 지도

## 사용자 결과

후보지에서 위치 정보를 가져오면, 글자로만 나오던 결과가 카카오맵 위에도 표시된다. 단지와 가장 가까운 초등학교, 중학교, 지하철역이 핀으로 보여서 주변 환경을 한눈에 파악하고, 임장 동선을 짜는 데 쓸 수 있다.

앱 전체 맥락은 루트 `PRODUCT.md`가 정한다. 이 작업은 `location-criteria`의 "주변 위치" 결과를 지도로 보여주는 확장이다.

## 승인된 범위

- 후보지의 "주변 위치" 패널에서 위치 정보를 가져오면 그 아래에 지도가 나타난다.
- 지도에는 다음이 핀과 이름표로 표시된다.
  - 단지: 가장 눈에 띄는 색으로 표시한다.
  - 가장 가까운 초등학교, 중학교, 지하철역: 종류를 구분할 수 있게 이름표에 "초", "중", "역"을 붙이고 이름과 거리를 보여준다.
- 지도는 단지와 표시된 시설이 모두 보이도록 범위를 맞춘다.
- 시설이 반경 안에 없으면 그 시설은 핀을 찍지 않는다.
- 지도 아래에 "카카오맵에서 크게 보기" 링크를 둔다. 누르면 새 탭에서 카카오맵이 단지 위치로 열린다.
- 지도를 표시할 수 없는 경우(JavaScript 키가 없거나, 지도 스크립트가 불러와지지 않음)에는 이유를 알려 주고, "카카오맵에서 크게 보기" 링크는 그대로 보여준다. 글자 결과와 매수 의견은 지도와 무관하게 동작한다.
- 지도는 위치 정보를 가져온 뒤에만 나타나며, 조회 결과와 마찬가지로 좌표를 저장하지 않는다. 새로고침하면 사라진다.
- 지도와 위치 데이터는 모두 카카오 것을 쓴다. 다른 지도 위에 올리지 않는다.

## 관찰 가능한 인수 기준

- 위치 정보를 가져오기 전에는 지도가 없고, 가져온 뒤에 지도가 나타난다.
- 지도에 단지 핀과, 조회된 시설 수만큼의 핀이 나타나고 이름표에 이름과 거리가 보인다. 반경 안에 없는 시설은 핀이 없다.
- 지도가 단지와 시설을 모두 포함하는 범위로 보인다.
- JavaScript 키가 없으면 지도 대신 설정 방법을 알리는 안내가 보이고, "카카오맵에서 크게 보기" 링크는 단지 좌표를 담은 주소로 열린다.
- 지도 스크립트가 불러와지지 않으면 오류 안내가 보이고 글자 결과, 의견, 링크는 정상이다.
- 단지와 시설의 좌표가 브라우저 저장소에 남지 않는다.
- 좁은 화면과 넓은 화면 모두에서 지도가 화면 폭을 넘지 않고 보인다.

## 확정한 제약과 이유

- **카카오맵 JavaScript SDK를 쓴다.** 위치 데이터가 카카오 로컬 API 결과라서 같은 카카오 지도 위에 표시하는 것이 약관상 가장 안전하다. 다른 지도 위에 올려도 되는지는 확인하지 못했다.
- **좌표는 저장하지 않는다.** `location-criteria`와 같은 이유다.
- **지도 키는 브라우저에서 쓰는 JavaScript 키다.** 로컬 검색용 REST 키와 다르며, 카카오 앱 설정에서 허용한 접속 주소에서만 동작하도록 제한한다.

## 가정 (사용자가 바꿀 수 있음)

- 지도의 기본 확대 수준은 모든 핀이 보이는 범위에 맞춘다.
- 핀은 카카오맵의 기본 마커와 이름표(커스텀 오버레이)로 그린다.
- 지도 크기는 높이 약 320px로 고정한다.

## 범위 밖과 이유

- 학원 위치 표시: 개수만 조회하고 위치 목록을 쓰지 않는다.
- 도보 경로 표시: 경로 데이터가 없다.
- 후보지를 등록하기 전 검색 단계의 지도: 거래 조회 결과에는 좌표가 없고, 지도를 위해 단지마다 위치를 조회하면 호출이 크게 늘어난다.
- 후보지 전체를 한 지도에 모아 보기: 좌표를 저장할 수 없다.

## 남은 위험

- **JavaScript 키와 접속 주소 등록이 필요하다.** 사용자가 카카오 앱 설정에서 JavaScript 키를 확인하고 `localhost`와 배포 주소를 등록해야 실제 지도를 확인할 수 있다. 이 값은 빌드 때 화면 코드에 들어가므로 배포 환경 변수를 바꾸면 다시 배포해야 한다.
- 주소가 등록되지 않았거나 키가 틀리면 지도가 비어 보일 수 있는데, 스크립트 불러오기 실패와 달리 이를 앱이 감지하지 못할 수 있다. 링크와 글자 결과는 항상 남긴다.
- 가장 가까운 시설이 단지에서 멀면(최대 2km) 지도가 넓게 축소되어 단지 주변이 작게 보인다.
- 단지 위치를 키워드 첫 결과로 정해 틀린 곳을 가리킬 수 있다. 지도가 그 오류를 눈에 띄게 하므로 사용자가 바로 알아볼 수 있다.
