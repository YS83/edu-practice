# 실거래가 인증키 디코딩 오류가 처리되지 않음

`app/api/trades/route.ts`에서 `DATA_GO_KR_API_KEY`에 `%`가 있으면 `decodeURIComponent`로 푸는데, 이 호출이 `try` 밖에 있다.

- 증상: 키에 잘못된 `%` 시퀀스가 있으면(예: 잘린 붙여넣기) `/api/trades`가 처리되지 않은 500을 돌려주고, 화면은 키 문제가 아니라 "서버에 연결하지 못했습니다"로 안내한다.
- 근거: `code-review low` 지적. 재현은 하지 않았고, 일반 사용 경로(정상 키 또는 키 없음)에는 영향이 없다.
- 다음 단계: 디코딩을 `try`로 감싸 실패하면 `missing-key`가 아닌 별도 오류(예: `bad-key`)로 돌려주고, 화면 문구도 맞춘다.
